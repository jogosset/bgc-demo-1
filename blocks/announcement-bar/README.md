# Announcement Bar Block

## Overview

A single-line promotional strip, typically placed directly under the site header (e.g. a shipping threshold, store hours, or seasonal message). Renders as a full-width colored band with centered text.

## Integration

### Content Model

A single row with one cell containing a paragraph. `<strong>` may be used inline to emphasize part of the message.
